## Local Development
```bash
npm install     # Installation
npm run dev     # Running locally
npm run build   # Build (output in dist/)
```

## Deployment
Import the repo into Vercel or Netlify (build command `npm run build`, output `dist`). Both serve HTTPS.

## CI/CD
`.github/workflows/deploy.yml` installs dependencies and builds on every push and pull request. Deployment is left to the host.

## Project Structure
`public/` static files (put your resume PDF in `public/resume/`), `src/data/` content, `src/styles/` CSS, `.github/workflows/` CI.
